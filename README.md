# 合成奶蛙

这是一个可直接部署到 GitHub Pages 的单页小游戏，玩法参考《合成大奶娃》：相同奶蛙碰撞后会合成更大的奶蛙。

## 本地试玩

直接双击 `index.html` 即可打开；如果浏览器限制本地文件，可在当前目录启动任意静态服务器后访问。

## 操作

- 电脑：移动鼠标瞄准，点击投放；方向键微调，空格或 Enter 投放，R 重开。
- 手机：在游戏区域拖动瞄准，松手投放。

## 发布给朋友

将本目录内的所有文件和 `assets/fruits` 文件夹上传到自己的公开 GitHub 仓库，并在仓库 Settings → Pages 中选择 `main` 分支和 `/ (root)`，等待部署完成后即可分享：

`https://你的用户名.github.io/仓库名/`
